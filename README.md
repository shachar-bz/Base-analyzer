# Base Analyzer

LLM imagery analysts look at satellite screenshots of suspected military bases. A Streamlit dashboard then shows what they found.

> Course project ("From idea to app"). Every analysis is generated by an LLM from public satellite imagery and may be wrong.

## How it works

1. **Collect** (`python -m base_analyzer`): for each base in a CSV list, the collector:
   - opens Google Earth in Chrome and takes a screenshot of the base;
   - sends up to 8 analysts (`gpt-5-nano`), one at a time. Each analyst sees a fresh screenshot plus the earlier reports, writes findings, and then chooses to zoom in, zoom out, move left, move right or finish;
   - has a commander (`gpt-5.4-nano`) read every report and write one summary with confidence levels;
   - saves the result to `data.json` and the first screenshot to `bases_screenshots/`.
2. **Explore** (`streamlit run streamlit_app.py`): the dashboard shows a map of all bases. Each base has its own page with the commander's summary and one tab per analyst. Object detection with [Moondream](https://moondream.ai) finds objects that you name in the screenshot.

## Setup

You need Python (tested with 3.14) and, for the collector only, Google Chrome.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # then add your keys
```

| Key | Needed for |
|---|---|
| `OPENAI_API_KEY` | the collector (analysts and commander) |
| `MOONDREAM_API_KEY` | object detection in the dashboard |

## Run the dashboard

```bash
streamlit run streamlit_app.py
```

`data.json` in this repo already holds 15 analyzed bases. The screenshots are not committed, so a fresh clone shows the analyses without images. Run the collector to generate the images again.

## Run the collector

Put the bases to analyze in `military_bases.csv` at the project root:

```csv
id,country,latitude,longitude
147,Egypt,23.95420291888193,32.99497151535935
```

```bash
python -m base_analyzer                # first 16 rows of military_bases.csv
python -m base_analyzer --csv other.csv --limit 5
```

The collector skips bases that are already in `data.json` and saves after each base, so you can stop it and run it again. Chrome stays visible on purpose. If Google Earth fails to load twice in a row, the collector stops, because Google has probably blocked it for now.

## Project layout

```
base_analyzer/
  __main__.py        collector entry point: wires the modules below together
  analysis_loop.py   analysts take turns; Camera and Analyst interfaces
  camera.py          Google Earth screenshots (Selenium)
  analyst.py         OpenAI analyst and commander
  base_store.py      data.json + bases_screenshots/, typed Base records
  object_detection.py  Moondream object detection for the dashboard
streamlit_app.py     dashboard
tests/
```

## Tests

```bash
pytest
```

The tests replace Chrome and OpenAI with fakes, so they need no API keys and no network.
